# 文章チェック専用への変更と類似ツール

調査日：2026-10-30。名称は仮称。検索結果だけで商標・名称の利用可能性を保証するものではありません。

## 今回の変更

AIチャットから、文章入力→端末内検出→候補選択→加工した文章のコピーに絞った。原文と加工後を同じ画面で確認し、候補にはルール／端末内AI／登録キーワード／手動の検出元を表示する。
チャットAPIは終了し、旧クライアントからの送信も410で拒否する。検出に外部推論API・APIキー・課金は不要。

## 既にあるもの

| ツール | 一次資料で確認した機能 | このアプリとの関係 |
| --- | --- | --- |
| [Presidio](https://presidio.dataprivacystack.org/) | NER、正規表現、ルール、チェックサム、文脈を使う個人情報の検出・匿名化。カスタマイズ可能。現在はコミュニティ主体 | 個人情報のルール＋MLによる検出そのものは既存の取り組み |
| [Privacy Filter Online](https://privacyfilter.app/) | ブラウザー内で個人名、連絡先、住所、口座番号、secrets等を検出・マスキング。初回にHugging Faceからモデル取得 | 端末内で検出し、マスキングする体験も既存。今回の方向にかなり近い |
| [presidio-local-anonymizer](https://github.com/gacabartosz/presidio-local-anonymizer) | Presidioを使うブラウザー拡張＋localhostバックエンド。AIサービス向けのテキスト匿名化 | ローカルで検出してAIへの入力を守る用途も既存 |

従って「世界初」「端末内AIだけで独自」という説明は避ける。今回磨く方向は、日本語の原文位置を維持した確認、個人情報と企業の未公開情報を同じ画面で扱うこと、検出元の説明、機密キーワードと手動選択で本人が補正できること。ただし、これらを唯一の機能と確認したわけではない。競合より優れた検出精度も未証明。

## 名前の案

1. `kotoba-filter` / ことばフィルター（推奨）：文章を入れて、共有する部分を選ぶ用途が伝わり、日本語中心のUIにも合う。
2. `sharecheck-local` / ShareCheck Local：共有前の確認と端末内処理が伝わる。
3. `text-privacy-check` / Text Privacy Check：機能が直感的。企業機密まで含めることは説明文で補う。

既存の `privacy-chat` はチャット専用に見えるので、今の用途には名前を変える方が合う。ただし、この変更ではGitHubのリポジトリ名・サイトURLは変更せず、アプリ内のみ仮称を採用した。
