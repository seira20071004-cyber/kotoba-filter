## 修正した問題

| 問題 | 修正後 |
| --- | --- |
| 名寄せで選択済みの機密保護が解除される | 原文の範囲で選択を引き継ぐ。名寄せの解除でも維持 |
| 未確認の機密候補を残したままコピーできる | 「隠す／内容を残す」の選択が済むまで停止。一括選択も用意 |
| 処理中の加工欄に原文が表示される | 完了前は加工欄を空にする |
| 改行が空白に正規化され、文・架空設定の境界が曖昧になる | 改行を文の境界に復元してから文を分割。原文位置を維持 |
| 挨拶・短い補足文への誤警告 | 具体的な情報を含まない定型表現のみを補助判定で除外 |
| 保護済みの連絡先だけなのに機密カードが重複する | PIIの保護を残して、定型文の重複カードを除外 |
| 長文の入力で末尾が切り捨てられる | 全文を残し、上限超過を表示してチェック・復元を停止 |
| 機密キーワード・復元結果等をまとめて消せない | 画面のデータ消去ボタンを追加。クリップボード・モデルキャッシュは対象外と明示 |
| 任意の復元欄が常時表示される | 対応表がある時だけ表示し、任意の折り畳み欄に変更 |
| 準備中の入力でモデル準備が中断する | 入力だけではモデル準備を中断しない。明示的な中止・消去では停止 |
| GPU探索中の中止後にWorkerが遅れて起動し得る | 準備の世代を確認し、古い準備の継続や古いエラーの適用を防ぐ |

「内容を残す」は本人の判断です。その候補の中で既に選択済みの個人情報は保護を維持します。本人が原文上の一部の範囲を調整することもできます。機密候補なしは安全の証明ではありません。

## 残る制限

会社ごとの本当の機密範囲、公開状況、架空設定という本人の記述の真偽は分かりません。個人情報の見落とし・誤検出、長文・引用・特殊な表現の誤判定は残り得ます。機密AIにはWebGPUが必要です。CPU経路とGPU経路の個人情報検出は異なるモデルです。端末内処理と、ブラウザー・OS・モデル取得先・クリップボードを含むシステム全体の安全性は区別する必要があります。
