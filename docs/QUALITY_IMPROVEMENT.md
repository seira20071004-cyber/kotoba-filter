# 見落とし・誤警告の改善（2026-10-31）

## 変更

1. 担当者の明示と「〜と申します」の日本語氏名を補助ルールで拾う。元の表記・敬語・絵文字・空白は維持する。部署、役割、未定等は補助ルールの氏名から除外する。
2. AIが確認候補にした文を、一般的な注意点・定義の質問と、具体的な非公開事実を含む文に分ける補助判定を追加した。単に「一般的」「架空」「公開済み」という単語があるだけでは除外しない。
3. 明示された架空設定の範囲を後続文にも引き継ぐ。段落の切り替わり、現実の組織・個人への言及、非公開指定等で範囲を解除する。PII検出はこの範囲にかかわらず行う。
4. 非公開を示す言い回しと資金調達・出資条件の具体的な検討が併記された場合は、補助ルールでも候補にする。一般的な用語解説とは区別する。

モデルの種類・重み・プロンプトは変更していない。文脈モデルが確認を完了した後に原文位置へ対応付けた補助判定を適用する。入力文・結果は引き続き外部推論APIへ送らない。機密候補は本人が選ぶ方式を維持する。

## 残る課題

- 「決まり次第お知らせします」「一般論として知りたいです」という短い補足文を、文脈AIが誤って候補にする例が残る。
- 既存の複合正例では「メールの署名文を考えてください」も誤警告される。今回の集計は文書単位なので、混在文内の余分な候補までは表の通常文数に含まれない。
- 日本語氏名の補助ルールはすべての名前・表現に対応しない。追加のルールには誤検出の可能性もある。
- 架空設定・一般論という本人の記述が事実かを検証できない。引用・混在文・長文の未見例は引き続き評価が必要。
- 1ブラウザー・自作の小規模な合成データであり、実世界の検出精度、全スマートフォン、競合への総合的な優位性、完全な情報漏えい防止を保証しない。モデルのスコアや速度・消費メモリーのベンチマークではない。
