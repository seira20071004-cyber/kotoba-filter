# ライトモード：専用PII検出・名寄せ・復元

更新：2026-10-30。完全匿名化や機密の完全除去を保証するものではありません。

## 端末内モデル

- GPU：[`openai/privacy-filter`](https://huggingface.co/openai/privacy-filter)、リビジョン `7ffa9a043d54d1be65afb281eddf0ffbe629385b`、q4、Apache-2.0。
- CPU：[`jiting/xlm-roberta-ner-japanese_onnx`](https://huggingface.co/jiting/xlm-roberta-ner-japanese_onnx)、リビジョン `8d70fc4d277a84e59ccc70520ffd9daff66e66f0`、q8、MIT。元は [`tsmatz/xlm-roberta-ner-japanese`](https://huggingface.co/tsmatz/xlm-roberta-ner-japanese) のONNX変換版。
- Transformers.js 4.3.2、ONNX Runtime Web。専用Web Workerで実行。入力文を推論サーバーへ送りません。
- GPU用OpenAIモデルの量子化演算は、確認したCPUランタイムでは起動できませんでした。このためCPUは日本語NER＋ルールです。両者の分類方針・精度・検出範囲は同じではなく、画面に実行環境を明示します。
- 初回は大きなモデルをHugging Faceから取得します。モデル・tokenizer・実行ライブラリーの通信とモデルキャッシュがあります。オフライン動作・全スマートフォンでの実行を保証しません。
- モデル重みはリポジトリや配布アーカイブに含めません。ブラウザー用ランタイムは配信のファイルサイズ制限に収まるよう分割し、端末内で結合します。

## 検出の処理

1. NFKC正規化・不可視文字除去の位置対応を保持する。
2. 連絡先、番号、認証情報、人名の表明・敬称付き表記、社名等をルールで補う。
3. GPUは専用モデルの33分類logitsから、BIOESの開始・遷移・終端を制約したViterbiデコードで8種類の範囲を求める。本実装は公開モデルの特定の校正済み動作点を完全再現したものではない。
4. CPUの日本語NERは人名・組織名・場所のラベルを連結する。メール、電話、カード、認証情報、誕生日等はルールで補う。NERによる一般的な場所・組織の誤検出もあり得る。
5. トークン境界のデコードを原文へ対応付ける。日本語の文字途中のバイト境界、絵文字、全角表記、tokenizerの空白処理へ対応。空白以外で対応が取れない場合は停止し、コピーを許可しない。
6. 長い入力は重なりのある範囲で確認し、全範囲が終了してからコピーを有効にする。アプリの入力上限は2,000文字。
7. メール・電話等の形式が明確なルール候補にモデルの一部分の名前・組織ラベルが重なっても、形式の整った候補を分割しない。

会社名はOpenAIモデルの独立した出力分類にはありません。ルール・本人が登録した語句で補います。CPUの日本語NERには組織分類があります。両者を同等と説明しません。

## 同じ情報の置換

同じ種類・同じ正規化値は同じラベルへ置換します。メール、電話、住所等も種類を示すラベルを使います。
別表記や代名詞を同一人物と推測して自動統合しません。検出済みの人物・組織を選び、原文の別表記・代名詞を本人が指定できます。統合先の表記へ復元します。
同じ名字の二人がいたり、代名詞が複数の人を指す場合などは本人の判断が必要です。手動で保護した箇所は名寄せの追加・解除でも維持します。

## AIの回答の復元

- 加工後の文章をコピーして、任意の外部AIに本人が貼り付けます。このアプリは外部AIの送信・回答取得を行いません。
- 回答をこの画面に貼り付けると、現在の置換表に完全一致したラベルだけを元の値へ戻します。
- ラベルには加工結果ごとにランダムな12桁の識別子を付けます。古い回答を別の置換表で誤復元することを減らします。
- AIに変更されたラベル・未知のラベルは推測で復元せず残し、警告します。一致なし・未知ラベルありの状態では復元結果のコピーボタンを有効にしません。
- 復元は一回の完全一致置換で、元の値に偶然別ラベルが含まれていても再帰的に置換しません。
- 入力編集、再チェック、選択変更、名寄せ、再読み込みで対応表と復元欄を無効化・更新します。
- 対応表・原文・復元結果はタブのメモリーと表示用DOMに限り、アプリDB・localStorage・推論事業者へ保存・送信しません。モデルのキャッシュは別です。
- 復元した文章には元の個人情報が戻ります。復元後のコピーは本人が確認して行います。

## 検証の読み方

`tests/fixtures/pii-ja-evaluation.json` の合成12例を使います。氏名、住所、英語氏名、全角連絡先、絵文字、誕生日、テストカード、同姓の人物、日常文・一般論が対象です。
指定した範囲が選択されているかと、加工後の文・型ラベルを確認します。少数例の動作確認であり、日本語全体の精度、競合への優位性、現実の漏えい防止率を示すベンチマークではありません。
既存製品との比較も同じ合成例の観察であり、相手製品の性能を一般化しません。
