# ことばフィルター 現行仕様

更新：2026-11-03。目的は「大切な情報の開示を減らしながら、使いたいAIに相談する」ことです。匿名化や機密の完全な検出を保証する製品ではありません。

## 利用の流れ

1. 文章を入力・貼り付ける。一度に確認できるのは2,000文字まで。上限超過時も勝手に切り捨てず、全文を残してチェックを停止する。
2. モードは「通常」と「機密情報も隠す」の二つ。既定は通常。通常は個人情報・金額・数量・商品名等の値を保護して説明を残す。後者は背景・事情まで保護する。ライトは画面から削除。内部の過去互換の検出関数は維持する。
モデルを先に準備している間も入力できる。入力変更だけではモデル準備を中断しない。明示的な中止・画面のデータ消去では準備も停止する。

3. 「文章をチェックする」を押すと、必要なモデルを準備し端末内で検出する。実行中・未完了・失敗時は加工欄を空にし、コピーを無効にする。
4. 個人情報と範囲の決まった保護候補は初期選択される。原文上のマーキングや候補の詳細で選択を調整できる。数量・商品名の書式を拡張。自動で分からない商品名・固有名詞は1文字から明示的に登録でき、このタブの原文中の一致箇所を保護する。
5. 範囲を決められない内容だけを追加候補としてまとめて表示する。手動で追加するか、隠していない内容が残ることを一つの確認欄で承認するまでコピーできない。範囲の決まった値のために一件ずつ確認する必要はない。推論自体の失敗は別扱いで、確認欄では解除できない。
6. 加工文を確認してコピーし、本人が任意の外部AIへ貼り付ける。アプリは外部AIへの送信を行わない。
7. 任意の復元欄を開いてAIの回答を貼り付け、現在の対応表で復元する。20,000文字を超える回答も勝手に切り捨てず、復元を停止する。

## 検出

- NFKC正規化・不可視文字の扱いと原文位置の対応を保持する。
- 個人情報はルールと専用モデル。GPUはOpenAI Privacy Filter、CPUは別の日本語NERモデル＋ルールであり、検出範囲・精度は同じではない。
- スタンダードの端末内AIには既にルールで検出した値を同じ文字数のプレースホルダーにして渡す。引用の検証は原文の単位を使い、AIの文字列を原文と取り違えない。値の置換後に既知のセンシティブな内容が残る場合も追加確認する。
- スタンダードはQwen2.5-1.5Bの端末内具体値抽出＋業務値の補助ルール。WebGPUが必要。会社ごとの秘密性や情報の公開状況を実際に照合する機能はない。
- フルセキュアは依頼と具体的な事実を句単位で分け、同じ境界を端末内AIにも渡す。質問が先にある文も検出する。公開・架空の説明は局所的に扱い、後続の実際の事情へ一律に引き継がない。
- 句点だけでなく改行も文の境界にする。空行では架空設定の範囲をリセットする。
- 一般論・短い挨拶・内容のない補足文だけなら、機密候補にしない補助判定を行う。同じ文に具体的な秘密が混在していれば一律に除外しない。
- 既に保護対象になった名前・連絡先だけの定型文は、機密確認のカードを重複表示しない。取引条件等の追加情報がある文は除外しない。
- AIが返す文ID・分類・引用を検証する。原文に存在しない引用・曖昧な繰り返し・全文引用は置換に使わず要確認にする。欠けた文IDや不正な構造は確認失敗としてコピーを止める。
- 理由は非公開指定・候補文の手がかり等に基づく定型説明で、秘密性を断定する根拠やAIの思考過程ではない。
- 「ルールのみ」は本人が明示的に選ぶ限定モード。AI失敗時の無言の切り替えは行わない。

## 選択・名寄せ・復元

- 同一種類・同じ正規化値は一貫したラベルへ置換する。ラベルには加工ごとの識別子を付ける。
- 別名や代名詞を同一人物と自動断定しない。本人が統合先を指定する。
- 名寄せの追加・解除で、既に隠していた機密内容や本人が解除した別の候補の選択を維持する。加工内容を変更したら、未確定候補についてのまとめて確認だけはリセットする。新たに指定した別表記は保護対象に加える。
- 名寄せ・選択変更・手動追加・再チェック等でラベルが変わる場合、古い対応表と復元欄は無効にする。
- 原文中の語句を手動で追加保護できる。会社固有のキーワードも登録できるが、このタブ内だけで使う。
- 復元は現在のラベルと完全一致したものだけ。フルセキュアで一般的な文章に言い換えた部分は自動復元しない。未知・改変されたラベルを推測で復元せず、復元結果のコピーを止める。

## データの扱い

- 原文、機密キーワード、検出結果、対応表、回答はタブ内のメモリーと表示用DOMで扱う。アプリDB・localStorage・外部推論APIへ保存・送信しない。
- モデル・実行ライブラリーの取得通信とモデルのブラウザーキャッシュはある。完全オフライン動作を保証しない。
- コピーは端末のクリップボードに行う。貼り付け先の処理はこのアプリの範囲外。
- 「この画面のデータをすべて消す」で入力・機密キーワード・対応表・選択・復元結果をリセットする。クリップボードとモデルキャッシュは消さない。OSやブラウザーのメモリーの安全消去を保証するものではない。
- 再読み込みで入力等は消える。アカウントへの文章の同期、入力履歴、自動送信は実装しない。

## 今回の見直しで直した点

- 名寄せで保護選択が初期化される問題を修正。
- 機密候補の未確認状態を区別し、確認前のコピーを停止。
- 実行中の加工欄に原文が表示される問題を修正。
- 改行が正規化で空白になり、文・架空設定の境界を誤る問題を修正。
- 短い補足文と連絡先だけの文への余分な機密警告を抑制。
- 長文の黙った切り捨てを避ける入力・復元上限処理へ変更。
- 画面のデータをまとめて消す操作とブラウザーの入力補正を無効にする指定を追加。

## 検証と残る制限

回帰テストは選択維持、コピー可否、改行位置、実際の秘密を含む混在文、重複候補、復元の境界等を確認する。モデルの意味理解精度の証明ではない。小規模な合成文と対応デスクトップブラウザーでの確認が中心で、未見の日本語、すべてのスマホ・Safari、入力内容の真偽や法的な機密性は保証しない。

機密候補がない場合でも、見落としがない証明にはならない。本人が原文・加工文を確認し、必要に応じてキーワード・手動追加を使う。


## 記号と置換のまとまり

自動のPII判定・文脈判定では、記号・句読点・空白だけのノイズを対象にしない。助詞だけの人名誤検出も抑える。一文字の実名を一律に除外せず、認証情報と本人が明示的に登録・手動指定した記号は別に扱う。PIIや名寄せによって値が分割されても、値の全体を選択した場合は元の範囲を一つのラベルにまとめ、記号だけのラベルを増やさない。


## 数値の意味と、選んだ箇所の追加保護（2026-11-03）

通常モードは、認識できた数量・金額・割合・期間の数値を隠し、単位や「以上・以下・未満」、日付の前後を結ぶ説明を原文のまま残します。例：`500セット以上` → `[数量1]セット以上`、`300万円` → `[金額1]円`、`28%` → `[割合1]%`（実際のラベルには加工識別子が付きます）。万・億などの桁情報は数値と一緒に隠します。概数・比率・増減率を計算して作りません。日付・識別子・商品名・自由な取引条件を無理に数値分割しません。

単位自体も秘密なら明示的なキーワード・手動指定を優先し、元の値全体を保護します。「機密情報も隠す」では単位の保持を強制しません。数値を隠した状態では、正確な損益計算などには回答できません。相談の意味が必ず保たれる保証ではありません。

チェック完了後、原文または入力欄の語句を選び「ここを隠す」を押すと、その出現箇所だけを追加保護します。繰り返す同じ語句の別の出現は変更しません。従来の手動入力・登録語句は一致箇所すべてを対象にします。既存の保護と本人が解除した別候補を維持します。選択しただけで未反映の間はコピーを止め、「ここを隠す」か「語句選択をクリア」で進みます。

入力・再チェック・保護の変更で選択スナップショットを無効にします。追加保護時は古い対応表・回答・復元結果と、未確定候補のまとめて確認をリセットします。数量・金額・割合・期間の新しいラベルも、現在の対応表との完全一致でのみ復元できます。
