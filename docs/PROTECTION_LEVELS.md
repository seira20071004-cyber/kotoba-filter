# 3段階の保護レベル

2026-10-30。保護レベルは、検出済み候補の自動選択範囲です。安全性の認証や回答精度の保証ではありません。

| レベル | 自動選択する候補 | 意図的に残ることがある情報 |
| --- | --- | --- |
| ライト | 人名、社名・所属、メール、電話、住所等、口座・カード番号、認証情報、本人登録の機密語・手動追加 | 見積額、注文番号、商品型番、一般の日付、数量・値引き条件、立場、関係性、機密の文章 |
| スタンダード | ライト＋金額・割合、注文・案件番号、型番、数量、日付・時期 | 立場・関係性、機密内容そのもの |
| フルセキュア | スタンダード＋検出した立場・役職、関係性、非公開内容の候補 | 見落とした情報や、文脈から推測できる事情が残る可能性 |

ライトでも完全な匿名化ではありません。「AIの回答精度MAX」「完全保護」という表現は使いません。スタンダードにも金額・数量等のルールベース置換という既存の手法を使っており、独自性や他製品に対する優位性を断定しません。

## 実装

- 原文は変更せず、正規化した文字列で候補を検出し原文範囲へ戻す。
- 従来のPIIルールへ、敬称付きの名前、略称の会社名、金額、割合、注文等の番号、商品型番、数量・日付・役職・関係性のルールを追加。
- 端末内AIは従来どおり文単位の機密候補を追加する。全段階でその候補を確認できるが、自動選択するのはフルセキュア。AIで個人情報の種類を精密に分類できると説明しない。
- 広いAI候補と細かなPII候補が重なっても、細かな保護範囲を維持するため境界で分割する。
- レベルを切り替えると、自動選択範囲と加工後の文章を再計算する。手動で解除した選択はレベルの初期選択に戻る。
- 同じ正規化値・同じ種類の候補は同じ `[人物1]` `[組織1]` などへ置換。別名・名字と姓名・代名詞を同じ実体と推測する名寄せは未実装。同じ人物でも表記が違えば別ラベルになる場合がある。
- スタンダードとフルセキュアでは、置換一覧を開き、各値と検出した種類に基づく説明を表示する。理由は固定のテンプレートで、推論による機密の断定ではない。
- コピーするのは加工後の文章だけ。原文との対応表と理由はタブのメモリー／表示用DOMだけで扱い、コピー・サーバー送信・永続保存しない。

## 限界

自由な文章の高度な言い換えを生成する実装ではなく、意味の種類を示すラベルへの置換。フルセキュアは文全体がラベルになり、相談に必要な意味が失われることもある。相談の目的に合わせた一般化・高精度の名寄せ・細かな契約条件抽出は今後の評価対象。

人名ルールは氏名の表明や敬称付き等の限定された形式。全人名を認識しない。商品型番・数量・日付等も定型の候補で、和暦や複雑な条件文などすべてを網羅しない。機密を含む文に対して一般的な表現があると見逃す場合もある。ルール・AIとも見落としと誤検出が残るので、原文と加工後を確認して調整する。

## 以前の検証

WebGPU対応のブラウザーで実モデルを動かし、同じサンプルで3レベルを切り替えて確認した。ライトでは金額・注文番号・日付・上司等を残し、人物・組織・メールを置換。スタンダードでは金額・業務番号・日付も置換。フルセキュアでは上司・担当者・社外秘指定や未公開計画の候補も置換した。スタンダードとフルセキュアで各置換の理由が表示されることを確認した。

自動テスト31件は、レベルごとの範囲、同じ値の一貫したラベル、広い機密候補とPIIの重なり、隣接した機密箇所の集約、原文に含まれるラベルとの衝突回避、手動選択、正規化、AI結果の形式等を確認する。検出精度のベンチマークではない。
