# スタンダードモード（2026-11-03）

ライトは個人情報の値だけを確認する。スタンダードは機密の具体値候補も抽出し、理由と原文を表示する。フルセキュアは別モードとして提供し、背景や内容まで広く保護する。

## 保持する情報と置換する情報

- 「電話番号は090(0000)0001です」→「電話番号は[電話1_識別子]です」
- 「ここからが社外秘です。見積金額は300万円、値引率は28%です」→「ここからが社外秘です。見積金額は[金額等1_識別子]、値引率は[金額等2_識別子]です」
- 注文番号、商品・開発名、型番、取引数量、個別の日付、支払条件、具体的な工程なども候補にする。役職や人間関係を一律に記号化しない。

## 実装

1. 従来の正規化・原文位置対応、PIIルール、専用PIIモデルを実行。
2. 業務文脈・非公開指定と業務値のルールを組み合わせ、候補値を抽出。氏名・連絡先だけの文、一般論や定型的な趣味の文、明示された公開情報への余分な警告を抑える。
3. Qwen2.5-1.5Bを端末内WebGPUで動かし、各文IDに対して公開/要確認と、原文の引用・固定の種類を構造化出力させる。
4. 文IDの網羅・構造・種類・原文との一致を検証。全角等は正規化後の位置から原文へ戻す。文中にない引用、曖昧な繰り返し、全文引用は自動置換に使わない。公開判定と候補が矛盾した場合は候補を検証して確認対象へ扱う。
5. 数値の説明ラベルを除外し、工程ではAIの要確認判定と限定した文型を組み合わせて具体手順を切り出す。理由は定型説明であり、AIの思考過程や機密性の法的判定ではない。
6. 原文の範囲を確定できない内容は「具体値を切り出せなかった箇所」として表示。文全体を勝手に隠さず、手動指定または原文が残ることの確認を求める。未確認のままコピーできない。「具体値をすべて隠す」だけでは、この未解決警告を確認済みにしない。
7. 値ごとに本人が隠す/残すを選ぶ。PIIは初期選択済み。機密を残す操作でもPIIの選択を維持する。対応表で現在のラベルだけを復元できる。

原文・対応表はタブ内のみ。外部推論APIやデータベースへの文章送信はない。モデル・ライブラリーの取得とキャッシュは存在する。AIが使えない時は無言で代替せず停止し、本人が明示的に「ルールのみ」を選べる。

## 制限

自由記述の企業秘密を網羅するものではない。公開/非公開や自社固有の秘密性を照合できず、検出漏れ・誤警告がある。説明・背景を残すこと自体が再識別や秘密の推測につながる場合もある。手動指定・機密キーワード・加工文の確認が必要。

原文が残ることの明示的な確認は、アプリが安全と判定したという意味ではない。値を特定できない時の確認表示も、すべての見落としを捕捉できるという保証ではない。

## 初期実装時の検証（2026-11-02）

- 自動テスト97件が成功。ライトの値保持、スタンダードの説明保持、理由、同じ値の一貫したラベルと復元、未確定時のコピー停止、AI引用の検証、Workerの不正ID停止を含む。
- 実ブラウザーのGPUで、PIIモデル＋Qwenを実行。見積額・値引率・注文番号・製品名・日付・支払条件の加工文で、説明・社外秘宣言・趣味の文が残ることを確認。
- 「社内の試験では、洗浄液を再利用せず毎回交換すると歩留まりが改善しました。この方法は社外秘です。」で、端末内AIと句抽出を実行。手順だけを[機密値]にし、試験の背景・結果・社外秘宣言を保持した。
- ルールのみでもライトとスタンダードの違いを確認。モード切り替えで古い加工文を消し、再チェックまでコピーできなくなることを確認。
- ルールのみで具体値を確定できない管理画面の文を確認。未確認時はコピー不可。手動で語句を隠し、明示的に確認した後だけコピー可能。

これらは合成ケースの機能検証であり、未知の文章での検出率や全端末での性能を示す評価ではない。AI単独の抽出ではなく、文脈判定と業務値・句抽出のルールを組み合わせている。

## 改善（2026-11-03）

- 「例えば」「一般論」等の単語だけで実際の取引値を対象外にしない。公開・架空・定義の説明は局所的な文脈ポリシーで扱う。「公開済み資料に載っていない」という否定は公開済み扱いにしない。
- 納期・納品・締切・公開予定の業務文脈を追加。日付や金額の範囲をAIがまとめて引用しても、具体値ごとに分離し、「から」「へ」「に変更」の説明を残す。近似金額や日付を勝手に生成するものではない。
- AIの引用が原文に存在しても、金額・日付・数量・番号の種類に合う形式がなければ値として採用せず、要確認にする。
- 既知のルール値は端末内AI向けの文で同じ文字数のプレースホルダーに置換し、重複抽出を省く。文ID・正規化後の文字位置は維持する。AIの引用の照合は加工前の原文の単位に対して行い、プレースホルダーの引用を原文の値として採用しない。
- 値を保護した後の残りの内容も検査する。システムの弱点や健康・法的事情等が残る場合は未解決警告とし、確認前のコピーを止める。未知の秘密をすべて見つける機能ではない。
- 純粋な依頼、公開・架空の設定、保護済みの値の説明だけの限定した定型文には重複警告を出さない。別の機密の事実が残る場合は除外しない。
